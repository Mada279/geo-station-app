الوحدات التشغيلية الحية على المنصة (Live Features)

استعراض دقيق للأنظمة الجاهزة والمفعلة على منصة الإنتاج المباشرة:

MODULE 01 · MARKETPLACE

سوق الأجهزة المركزي (بيع وتأجير)

سوق رقمي مفتوح يتيح للشركات والمهندسين البحث عن معدات المساحة (Total Station, GNSS, 3D Scanners, Levels) وفلترة النتائج حسب المحافظة، الماركة، الحالة، ونوع التعاقد، مع عرض بيانات المكتب المعتمد المالك للجهاز.

✓ استعلام لحظي من قاعدة بيانات Supabase
✓ فلترة متعددة المستويات في كسر من الثانية
✓ ربط مباشر بكتالوج الأجهزة المعتمد
✓ استيراد أوتوماتيكي لصور ومواصفات الماركات العالمية
MODULE 02 · DIRECTORY

دليل المكاتب والشركات المعتمدة

دليل هندسي موثوق يعرض المكاتب وشركات المساحة المعتمدة رسمياً داخل جمهورية مصر العربية، مع فلترة جغرافية للمحافظات وعرض بيانات الاتصال والتخصصات الدقيقة.

✓ عرض المكاتب المعتمدة فقط (Approved Status)
✓ شارات التوثيق الهندسي المعتمدة
✓ البحث بالاسم والمدينة والتخصص
✓ معالج تسجيل الموردين المتعدد المراحل (Wizard)
MODULE 03 · SERVICES MODULE

منظومة الخدمات المساحية المتخصصة

وحدة هندسية معزولة تماماً تُمكّن المكاتب من إدراج خدماتها المهنية (مساحة أرضية، مساحة قانونية، خدمات فنية ومعايرة، جيوفيزياء وكشف مرافق، Reality Capture، تصوير جوي بالدرون)، مع عرض المخرجات الهندسية للمشروع.

✓ فصل كامل عن منطق المعدات لمنع التداخل
✓ إضافة وحذف الخدمات من لوحة تحكم المورد
✓ عرض المخرجات الأساسية (AutoCAD, Point Cloud)
✓ فلاتر سريعة حسب الفئة الهندسية
MODULE 04 · LEAD CAPTURE

زر التواصل الذكي واصطياد العملاء (Lead Engine)

آلية تحويل مبتكرة تمنع تسريب بيانات الموردين مجاناً؛ حيث يطلب النظام تسجيل الدخول قبل كشف الهاتف، وعند الضغط يقوم بتسجيل العميل كطلب اهتمام مؤكد (Lead) في قاعدة البيانات وفتح محادثة واتساب موجهة فوراً.

✓ حماية أرقام هواتف الموردين ومنع التطفل
✓ فتح واتساب بنص معبأ مسبقاً باسم المعدة أو الخدمة
✓ رصد فوري للـ Lead في جدول lead_tracking السحابي
✓ اتصال هاتفي مباشر بلمسة واحدة

01 تمهيد وإقرار الأهلية

لما كان الطرف الأول يرغب في تطوير وتدشين أول منصة وسوق رقمي مركزي لقطاع المساحة والجيوماتكس تحت اسم العلامة التجارية (Survsta)، ولما كان الطرف الثاني يمتلك الخبرة الهندسية والتقنية لتنفيذ وبرمجة النظام وفق أفضل المعايير المؤسسية، فقد اتفق الطرفان بكامل أهليتهما المعتبرة قانوناً على إبرام هذا العقد كملحق تنفيذي وتسليمي نهائي لمشروع المنصة.

02 نطاق التسليم ومخرجات الإصدار الأول (MVP Scope)

يقر الطرف الثاني بأنه قام بإنجاز وبرمجة وتسليم كافة الأنظمة والوحدات الوظيفية الموضحة تفصيلاً في هذا التقرير الفني المرفق، وتشمل تحديداً:

  • سوق المعدات المركزي (Marketplace): بكامل خيارات الفلترة المتقدمة للماركات والمحافظات ونوعية التعاقد (بيع / إيجار).
  • دليل المكاتب المعتمدة (Directory): مع منظومة تسجيل وتدقيق الموردين عبر لوحة التحكم.
  • منظومة الخدمات المساحية (Services Module): المعزولة برمجياً لتقديم خدمات المسح الأرضي، الطبوغرافي، والتصوير الجوي.
  • زر التواصل واصطياد العملاء (Smart Lead Button): لحماية بيانات الموردين والتوجيه الذكي لمحادثات الواتساب مع تسجيل الـ Leads حياً.
  • لوحات التحكم (Dashboards): لوحة تحكم المورد لإدارة الأسعار والأجهزة والخدمات، ولوحة إدارة المشرف العام (Admin).
  • المعمارية السحابية: بناء النظام عبر Next.js 14 وقاعدة بيانات PostgreSQL سحابية على Supabase واستضافة سريعة على Vercel مع ربط النطاق survsta.com.
